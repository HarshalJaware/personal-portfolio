# Personal Portfolio

A professional personal portfolio built with React and modern frontend technologies.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- ESLint
- Prettier

## Development

Install dependencies:

```bash
npm install
````

Run development server:

```bash
npm run dev
```

Run lint:

```bash
npm run lint
```

Create production build:

```bash
npm run build
```
